# おすすめスポットの追加方法

1. スマートフォンで https://app.pagescms.org/ を開き、GitHubアカウントでログインします。
2. `AkiraItoi/campingcar-hp` を選び、「おすすめスポット」を開きます。
3. 行を追加し、施設名、種類、自分で撮影した写真、一言コメント、公式サイトURLを入力します。
4. 掲載する前に「LPに掲載する」をオンにし、保存します。保存するとGitHubにコミットされ、Vercelの次のデプロイ後に表示されます。
5. 並べ替えや修正も同じ画面で行います。画像が未設定、URLが無効、掲載がオフの行は表示しません。

## 初回だけ必要な接続

Pages CMSのGitHub Appをリポジトリ所有者がインストールし、対象を `campingcar-hp` のみに限定します。これは第三者サービスへのリポジトリ書込権限の付与なので、所有者が権限画面を確認して実行してください。本PRをmainに取り込んだ後に接続します。

写真は自分で撮影したJPEG/PNG/WebPを利用します。iPhoneのHEIC写真は対応形式に変換してから登録してください。写真をできれば1～2MB程度に抑えると表示が軽くなります。施設の公式URLはhttps://から入力します。Instagram/Facebook URLは将来の連携に備えた任意の保存欄で、現段階ではLPには表示しません。

公開ページに投稿者向けの入力口は置きません。LPは `data/spots.json` の掲載済み行のみを表示し、写真は `img/spots` 内を参照します。施設が一つも掲載されていない間、セクションは非表示です。予約関連ファイルには依存しません。
